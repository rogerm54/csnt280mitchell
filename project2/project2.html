CSNT280 Project 2 - A simple web application that allows users to add proposals

This project will build on the PostgreSQL database created in Lab 7 and will create the ability for users to login and add proposals. When the user adds a proposal, the user can designate other usernames that are associated with the proposal. This means that the underlying database will need to support a many-to-many relationship between the users table and the proposals table.

The users passwords will be stored as doubly-hashed randomly salted passwords. The salts and passwords will be added in the same manner as Lab 7. You will utilize the lab7_db database as the backend database for this project. However, you will need to add additional tables and views to complete the backend.

For a web application, there are some basic steps that should be carried out:

  1. Develop as much of the backend database and database functionality as possible without involving any PHP scripts. For this project, unlike Project 1, this is easier to do because we are using the pgcrypto extension and plpgsql functions to do the authentication.
  2. To complete the database backend, add some initial data so that querying the tables and view can be checked. This will provide some initial data to help developing the PHP front-end.
  3. When starting on the PHP scripts, determine the correct IP address to connect from PHP to the backend PostgreSQL database. Make sure that you can get a connection from your PHP scripts.
  4. For the PHP scripts, create "login.php" and "handleLogin.php" to allow a user to login. Upon successful login, redirect the user to "home.php" where all the proposals that the user is associated with will be displayed. The page that "home.php" displays will need to have a link that allows adding in proposals.
  5. Additional PHP scripts can then be developed. These scripts include "addProposal.php" and "handleAddProposal.php". The "addProposal.php" page will be a form page that allows the user to input the proposal and the additional usernames associated with the proposal. The "handleAddProposal.php" will be calling a plpgsql function made (in step 1) to add the proposal.
