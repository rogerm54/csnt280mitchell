GUI Programming using PySide

One of the best ways to do GUI (Graphical User Interface) programming in Python is to use the PySide framework. This is the completely free port of the PyQt framework. PySide has a large number of widgets that make it straightforward to create a GUI application. The following is an introduction to creating a simple GUI application that makes use of some of the common functions in PySide.

Naming conventions in PySide

The naming convention for classes, functions and properties in PySide is similar to the naming convention for Java. That is, classes begin with a capital letter while functions and variables start with a lower case letter. The names use camel case, so every new word that makes up a name is capitalized. Understanding the naming convention is helpful in understanding online documentation.

PySide Installation

To install PySide on Ubuntu 16.04, use the following command: 


sudo apt-get install python3-pyside

PySide documentation

The closest version of PySide documentation to the version that will be installed, is the PySide 1.2.1 documentation. The documentation for version 1.0.7 is close enough to also be useful.

A simple GUI program

Here is the code for a very simple GUI program. It just consists of a titled window that has a close button, minimize button and resize/maximize button. 


from PySide import QtGui, QtCore
import sys
class MyGui(QtGui.QMainWindow):
    def __init__(self):
        QtGui.QMainWindow.__init__(self)
        self.setGeometry(50,50,700,400)
        self.setWindowTitle("My GUI Program")
        self.show()

app = QtGui.QApplication(sys.argv)
mygui = MyGui()
sys.exit(app.exec_())

Line 1 imports the QtGui and QtCore modules from the PySide module. The QtGui and QtCore modules are used for just about any PySide program, so consider this a standard import statement. Line 2 imports the sys module that is needed to start up the application.

Lines 3-8 define the MyGui class. Line 3 makes it so that MyGui inherits from the QtGui.QMainWindow class. This will give MyGui all the important properties for behaving as the main window of a GUI application.

Lines 4-8 define the constructor for the MyGui class. Note that in Python, the constructor for a class is always named __init__. Line 5 calls the constructor of the parent class, QMainWindow. Line 6 sets the bounds for the application. In this case, the upper left corner will start at (50,50) and the window will be 700 pixels wide by 400 pixels high. Line 7 sets the title to "My GUI Program", and line 8 causes the window to be displayed.

Line 10 creates a QApplication object. Line 11 creates the main window object by calling the constructor for the MyGui class. Line 12 launches the QApplication object. Lines 10-12 are that standard way that any PySide GUI application is launched.

This file is saved as "mygui.py". To launch the program, run the following command from a terminal that is in the directory containing "mygui.py": 


python3 mygui.py

Adding a menu

Next, let's add a menu. The menu will start off just being a File menu with a Quit menu item that causes the application to end. Here is the modified version of "mygui.py". 


from PySide import QtGui, QtCore
import sys
class MyGui(QtGui.QMainWindow):
    def __init__(self):
        QtGui.QMainWindow.__init__(self)
        self.initMenu()
        self.setGeometry(50,50,700,400)
        self.setWindowTitle("My GUI Program")
        self.show()
        
    def initMenu(self):
        menubar = self.menuBar()
        fileMenu = menubar.addMenu("File")
        quit = QtGui.QAction("Quit",self)
        quit.triggered.connect(self.close)
        fileMenu.addAction(quit)

app = QtGui.QApplication(sys.argv)
mygui = MyGui()
sys.exit(app.exec_())

The new lines, shown with a different background, are line 6 and lines 11-16. Line 6 just calls the initMenu() function that is defined on lines 11-16. The initMenu() function defined on lines 16 creates the menu system for this application. Line 12 creates the menu bar. Line 13 adds the File menu using the addMenu() function and stores a reference to this menu called fileMenu. This reference, fileMenu, is used on line 16 to add the Quit menu item. Line 14 creates a QAction object called quit. Menu items are QAction objects. Note that when a QAction object (menu item) is created, the second argument is self. That refers to the QMainWindow object (the main window). This ties the menu item to the main window allowing the main window to respond to the user selecting that menu item. Line 15 connects the close() function to the event that the user selects the Quit menu item. The close() function is one of the functions that is inherited from the QMainWindow class. This is why you don't define the close() function, because it is inherited from QMainWindow.

If you run the program now, you will be able to select Quit on the File menu and end the application.

Adding a text area

Let's add a text area to the application. Here is the new version of the program: 


from PySide import QtGui, QtCore
import sys
class MyGui(QtGui.QMainWindow):
    def __init__(self):
        QtGui.QMainWindow.__init__(self)
        self.initMenu()
        self.text = QtGui.QTextEdit()
        self.setCentralWidget(self.text)
        self.setGeometry(50,50,700,400)
        self.setWindowTitle("My GUI Program")
        self.show()
        
    def initMenu(self):
        menubar = self.menuBar()
        fileMenu = menubar.addMenu("File")
        quit = QtGui.QAction("Quit",self)
        quit.triggered.connect(self.close)
        fileMenu.addAction(quit)

app = QtGui.QApplication(sys.argv)
mygui = MyGui()
sys.exit(app.exec_())

The new lines, shown with a different background, are lines 7 and 8. Line 7 creates a QTextEdit object that will serve as a text area. Line 8 sets this text area to be the central widget. Being the central widget will mean that this text area will take up the main part of the applications main window.

Adding an Open menu item

Let's add another menu item to the File menu. We will add a menu item (QAction) labeled Open that will cause a file open dialog to be displayed. Here is the new version of the program: 


from PySide import QtGui, QtCore
import sys
class MyGui(QtGui.QMainWindow):
    def __init__(self):
        QtGui.QMainWindow.__init__(self)
        self.initMenu()
        self.text = QtGui.QTextEdit()
        self.setCentralWidget(self.text)
        self.setGeometry(50,50,700,400)
        self.setWindowTitle("My GUI Program")
        self.show()
        
    def initMenu(self):
        menubar = self.menuBar()
        fileMenu = menubar.addMenu("File")
        open = QtGui.QAction("Open",self)
        open.triggered.connect(self.openFile)
        fileMenu.addAction(open)
        quit = QtGui.QAction("Quit",self)
        quit.triggered.connect(self.close)
        fileMenu.addAction(quit)
        
    def openFile(self):
        filename, _ = QtGui.QFileDialog.getOpenFileName(self,
            "Open File",".")
        if (filename != ""):
            infile = open(filename,"r")
            contents = infile.read()
            infile.close()
            self.text.setText(contents)

app = QtGui.QApplication(sys.argv)
mygui = MyGui()
sys.exit(app.exec_())

The new lines, shown with a different background, are lines 16-18 and lines 23-30. Lines 16-18 add the new Open menu item. Line 16 creates the QAction object that serves as the new menu item. Line 17 connects the event associated with selecting that menu item with the openFile() function defined on lines 23-30. Line 18 adds the menu item to the File menu.

Unlike the close() function referred to on line 20, the openFile() function is a function that we need to define ourselves. Lines 24-25 cause a file open dialog box to be displayed. The second argument, "Open File", will be shown in the title bar of that dialog box. The third argument, ".", will cause that dialog box to start looking for files in the current directory. Lines 26-30 define an if statement that will be executed if the user selects a filename. Line 27 will open that file for reading, storing the file handle as infile. Line 28 will use the read() function to read the entire contents of the file and store this as contents. Line 29 closes the input file handle. Line 30 sets the contents of the text area to be the contents of the input file. If you try this out, make sure you select a text file.
