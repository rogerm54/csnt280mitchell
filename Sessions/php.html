Introduction to PHP

PHP (PHP: Hypertext Preprocessor) is a scripting language that was designed for creating active web pages. It originated in 1995 and has been widely used for a number of years. Although other ways of creating web pages (JSP, ASP and Ruby on Rails) have come about more recently, PHP is still used in a large number (over 70%) of web sites.

Syntax, variables

The syntax for the PHP language is similar to C or Java, in that every statement ends with a semicolon, and indentation is recommended but not required. Blocks are enclosed in curly braces ({ }) like C and Java.

Variables in PHP must start with a $ symbol. Like other scripting languages (like Perl or Python), variables in PHP are duck-typed. This means that the type of a variable in PHP is determined by how the variable is used. Consider the following examples: 


$count = 5; // an integer 
$name = "John Doe"; // a string
✴ ✴ ✴ ✴ ✴

Programmers coming from other languages will often need to get used to the requirement that all variables begin with the $ symbol in PHP. A very common place to make this mistake is when defining the range over which a for loop will iterate. Don't forget to use $i instead of i: 


for ($i = 0; $i < 10; $i++) { }
✴ ✴ ✴ ✴ ✴

Simple output

To output something to a web page, you can use the echo command or the print() command. Besides the print() function requiring parentheses around the arguments, there is little difference between these two functions. Most PHP programmers use the echo function. Here are some simple examples of using the echo command. 


<?php
  echo "Hello\n"; 
  $name = "John Doe"; 
  echo "Hi $name\n";
?>

Line 3 defines a variable called $name. Line 4 makes use of variable interpolation to substitute in the value of the variable when a variable name is enclosed in double quotes. Here is the output of this program when run from the command line: 


$ php -f echo.php
Hello
Hi John Doe

Difference between single and double quotes

When specifying PHP strings, the use of single and double quotes have different meanings. Single quotes are used for literal strings. Double quotes are used if you want variable interpolation to take place in the string. Double quotes are also needed if you are using escape codes like \n (new line) and \t (tabs). The following PHP program shows the difference between using single and double quotes for a string. 


<?php 
  $name = "John Doe"; 
  echo "Hello $name" . "<br />\n"; 
  echo 'Hello $name' . "\n"; 
?>>

Line 3 uses double quotes, so the value for $name is substituted. Line 4 uses single quotes, so the literal string is printed. This is shown running the program at the command line: 


$ php -f echo2.php
Hello John Doe

Hello $name

The concatenation operator is the dot (.)

Looking back at the previous code, note on lines 3 and 4, that the operator for concatenation is the dot (.). The + operator in PHP is only used to add numbers. This is different from languages like Python, Java or C.

✴ ✴ ✴ ✴ ✴

Be careful when trying to concatenate variables in PHP. If you try to use the + operator to concatenate strings, this will not generate a syntax error. But, the result will not be what you wanted. As long as you use the dot (.) operator, you can contenate strings with numbers. The numbers will be converted to strings and then concatenated, similar to what happens in Java. See the following example: 


<?php
  $x = "hot";
  $y = "dog";
  echo $x + $y; // don't do this
  echo "\n";
  echo $x . $y;
  echo "\n";
  $n = 5;
  echo $x . $n . "\n";
?>

When run at the command line, this is what is produced: 


$ php -f test.php
0
hotdog
hot5
✴ ✴ ✴ ✴ ✴

Arrays in PHP

PHP arrays are like Python lists. PHP arrays can grow in size and the array elements can be of more than one type. Consider the following simple example: 


<?php
  $things = array('cat',5);
  $things[] = 'dog';
  $things[] = 'cow';
  print_r($things);
  echo $things[1] . "\n";
  echo $things[3] . "\n";
?>

Line 2 creates an array with the first element a string with the value "cat". The second element is a number with the value 5. Lines 3 and 4 demonstrate how to append to the end of the array. You just use the array name followed by empty brackets ([ ]) and assign the value you want appended to the array. Line 5 uses the print_r() function to print the array. The print_r() function is made specifically for printing arrays. Lines 6 and 7 show that array access using an index works the same as accessing arrays in Python, Java or C. Here is the output of this program run at the command line: 


$ php -f array1.php
Array
(
    [0] => cat
    [1] => 5
    [2] => dog
    [3] => cow
)
5
cow

Associative Arrays

You can also use associative arrays. These are arrays that use a string key instead of an integer index. Like index-based arrays, you can simply add new elements. Consider the following example: 


<?php
  $favorites = array();
  $favorites["animal"] = "cat";
  $favorites["number"] = 7;
  $favorites["food"] = "pizza";
  print_r($favorites);
  echo $favorites["food"] . "\n";
?>

Line 2 initializes an empty array. Lines 3-5 add elements to this associative array. Line 6 uses the print_r() function to print the entire array. Line 7 demonstrates how the associative array is accessed. Here is the output when this program is run from the command line: 


$ php -f array2.php
Array
(
    [animal] => cat
    [number] => 7
    [food] => pizza
)
pizza

Because the key for an associative array is a string, this makes it easier to figure out what the code is doing. It is more descriptive to use this: 


echo $favorites["food"];

than this: 


echo $favorites[2];

Therefore, you should favor using associative arrays over index-based arrays.

Repetition statements

For loops

The most straightforward way to process an array in any language is a for loop. PHP is no exception. Here is an example of the most common way to use a for loop to print out an array in PHP: 


<?php
  $animals = array('cat','dog','horse','cow');
  for ($i = 0; $i < count($animals); $i++) {
    echo $animals[$i] . "\n";
  }
?>

On line 2 we create an array. Lines 3-5 define a for loop that will print out all the animals. On line 3, the the for loop is setup similar to Java or C. The first statement is the initializing statement, and this sets $i = 0. The second statement is the terminating condition. When the second statement becomes false, the for loop ends. Note the count() function is used to return the number of elements in the array. Finally, the third statement sets the increment for the loop variable. As mentioned before, it is important to use $i, not i, for the loop variable. The following shows the output that is produced when this program is run on the command line: 


$ php -f for_loop.php
cat
dog
horse
cow

While loops

While loops in PHP are similar to while loops in many other programming languages. Here is a simple example of a while loop: 


<?php
  $x = 7;
  while ($x > 3) {
     echo "x is $x\n";
     $x--;
  }
?>

As can be seen, the while loop continues as long as the test condition is true. Note on line 4 how variable interpolation is used to print the value of $x. The output that is produced when this program is run is: 


$ php -f while1.php
x is 7
x is 6
x is 5
x is 4

What is somewhat unique about the PHP language is how boolean expressions evaluate to true and false. It turns out that any array element or record from a recordset that is not NULL evaluates to TRUE, while a NULL element or record evaluates to FALSE. This makes a program like the following work: 


<?php
  $animals = array('cat','dog','horse','cow');
  echo current($animals) . "\n";
  while ($animal = next($animals)){
    echo "$animal\n";
  }
?>

The current() function on line 3 returns the current array element without advancing the internal array pointer. The next() function on line 4 advances the internal array pointer and returns the element in that position or FALSE if the pointer has gone beyond the end of the array. So, when the internal array pointer goes past the end of the array, the while loop will stop. The following shows the output when this program is run on the command line: 


$ php -f while2.php
cat
dog
horse
cow
